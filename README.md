💰 Smart Expense Tracker

A modern and user-friendly web application designed to help users track their daily expenses, manage their budget, and understand their spending habits.

🚀 Features

➕ Add new expenses easily

🗑️ Delete expenses

💰 Set an initial balance

📊 Track total expenses and remaining balance

🏷️ Categorize expenses

🔍 Filter expenses by category

⚠️ Daily spending limit warning

📅 Track expenses by date

📱 Responsive and user-friendly interface

⚡ Fast frontend-backend communication using REST APIs

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/smart-expense-tracker.git
cd smart-expense-tracker

2. Install Backend Dependencies

cd server
npm install

3. Start the Backend

npm start

The backend will run on:

http://localhost:5000

4. Install Frontend Dependencies

Open another terminal:

cd client
npm install

5. Start the Frontend

npm run dev

The application will run on:

http://localhost:5173

🎯 How It Works

1. Enter your initial balance.


2. Add your daily expenses.


3. Select a category for each expense.


4. Monitor your total spending.


5. Check your remaining balance.


6. Get warnings when you exceed your daily spending limit.


7. Filter expenses to better understand where your money is going.
